# Character UID Contract (Dependency for Plan 30edf8be)

This document defines the identity contract expected by the separate currency plan `30edf8be`.
For full implementation details, migration behavior, and troubleshooting, see `RTCharacterUid-Documentation.md`.

## Guarantees

- `HumanoidCharacterProfile.CharacterUid` is globally unique.
- `CharacterUid` is generated by the server when a profile row is created.
- For existing profiles, updates preserve the original `CharacterUid`.
- Deleting and recreating a slot yields a new `CharacterUid`.
- Database enforces uniqueness with `IX_profile_character_uid`.

## Non-goals in this change set

- No currency balance tables.
- No transaction ledger.
- No economy transfer logic.

## Usage expectation for downstream plan

- Use `CharacterUid` as the stable key for character-bound currency.
- Use account `UserId` for account-bound currency.
